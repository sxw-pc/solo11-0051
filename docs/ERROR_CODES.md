# 错误码与告警速查

错误与告警都带稳定前缀。`PLAN-*`、`PIPE-*`、`DATA-*`、`SAMP-002/003`、`LEDGER-*`、`REPORT-*`、`CLI-*` 是异常，命令通常返回非零；`SAMP-101..103`、`COV-*`、`DEV-*` 是核验告警，会进入报告和台账，但不会中断流水线。

## 方案与配置

| 代码 | 含义 | 建议处置 |
| --- | --- | --- |
| `PLAN-001` | 缺少必填字段，或模式要求的条件字段缺失。 | 按错误路径补齐字段；错误消息会给出 YAML 节点路径和可用行号。 |
| `PLAN-002` | 字段类型或结构错误（含布尔伪装整数、列表形状不符）。 | 按 DSL 指定类型修改；整数不要加引号或写成字符串。 |
| `PLAN-003` | `apiVersion` 或 `kind` 不匹配。 | 使用 `samplelaw/v1` 与 `SamplingPlan`。 |
| `PLAN-004` | 枚举值或排除操作符不受支持。 | 检查 mode、on_shortfall、operator。 |
| `PLAN-005` | 数值越界（如总量非正）、列表为空或重复列无效。 | 使用正整数；显式 `fingerprint.columns` 不得为空。 |
| `PLAN-006` | 分层键、预期层、指纹列或偏离维度重复。 | 去重；层的顺序仅在预期层展示时保持声明顺序。 |
| `PLAN-007` | 比例/阈值越界。 | `rare_threshold` 在 `(0,1]`；其他阈值在 `[0,1]`。 |
| `PLAN-008` | 模式与字段互斥冲突。 | `fixed` 只用 `per_stratum`；其他模式只用 `total_size`。 |
| `PLAN-009` | 排除条款形状错误。 | `eq/neq` 用标量，`in/not_in` 用非空列表，并提供 `column`。 |
| `PLAN-011` | 最小值/最大值/固定量互相冲突。 | 调整为 `min <= per_stratum <= max`，或 `min <= max`。 |
| `PLAN-012` | YAML 解析失败。 | 检查缩进、冒号和文档结构；错误含解析行号。 |
| `PLAN-013` | 发现未知字段。 | 移除拼写错误字段；DSL 不做未知字段透传。 |
| `PLAN-014` | 方案文件不存在或不可读。 | 检查路径；流水线内路径相对 pipeline YAML 所在目录解析。 |
| `PIPE-001` | 流水线缺少必填字段（如 jobs、名称、SQLite table）。 | 补齐配置。 |
| `PIPE-002` | 流水线字段类型错误。 | 对照 `examples/pipeline.yaml` 修正。 |
| `PIPE-003` | 流水线引用文件不存在（方案、源数据或配置文件本身）。 | 使用相对配置目录的路径或绝对路径。 |
| `PIPE-004` | 流水线枚举/版本不匹配。 | 使用 `samplelaw/v1`、`Pipeline`、支持的报告格式和源类型。 |
| `PIPE-005` | 作业 ID、格式列表或字段取值非法。 | ID 仅用字母、数字、`_`、`-`；至少一个 job。 |
| `PIPE-006` | 重复的作业 ID 或报告格式。 | 去重。 |
| `PIPE-007` | 流水线未知字段。 | 移除或修正字段。 |
| `PIPE-008` | 流水线 YAML 解析失败。 | 检查 YAML 语法。 |

## 数据源

| 代码 | 含义 | 建议处置 |
| --- | --- | --- |
| `DATA-001` | CSV / SQLite 空表，或没有数据行。 | 提供至少一行数据；空表无法完成抽样。 |
| `DATA-002` | 缺少分层键、指纹列、排除列、偏离维度等。 | 核对表头和方案字段；列名大小写敏感。 |
| `DATA-003` | CSV 无法按 UTF-8-SIG / UTF-8 / GBK 解码。 | 另存为 UTF-8，或在 source 显式指定编码。 |
| `DATA-004` | 文件缺失、CSV 结构损坏、重复/空列名、SQLite 读取失败或表不存在。 | 检查路径、表名、CSV 表头与字段数量；SQLite 以只读 URI 打开。 |

## 抽样与判定

| 代码 / 状态 | 类型 | 含义 | 建议处置 |
| --- | --- | --- | --- |
| `SAMP-001` | 异常 | 排除后无可抽行，或抽样结果为空。 | 放宽排除条款或补充源数据。 |
| `SAMP-002` | 异常 | `on_shortfall: fail` 且某层可用行低于要求。 | 补充数据、降低最小量或改用 `warn`。 |
| `SAMP-003` | 异常 | 分配器无法消费目标席位（内部一致性错误）。 | 检查冲突边界；提交最小复现。 |
| `SAMP-101` | 告警 | 层内可用数据不足，实得量低于计划目标。 | 查看报告中的 target/actual 差异；必要时补充数据。 |
| `SAMP-102` | 告警 | 实际总量因最小覆盖或容量/上限而调整。 | 属保护行为；如需严格总量，调整 `total_size` / `max_per_stratum`。 |
| `SAMP-103` | 告警 | 预期层在源数据中为空。 | 检查分类字典、上游过滤或排除条款。 |
| `REPLAY-001` | 结论 | `INSUFFICIENT_INPUT`：源或样本无行，无法重放。 | 补齐源数据或落盘样本。 |
| `REPLAY-002` | 结论 | `DIVERGED`：重算结果与样本存在缺失/多出/顺序差异。 | 对照源指纹、样本改动、种子、排除条款和顺序比较设置排查。 |
| `MATCH` | 结论 | 重放一致。 | 无需处置。 |
| `COV-000` | 告警 | 落盘样本为空。 | 检查样本文件与上游任务。 |
| `COV-001` | 告警 | 稀有层没有命中样本。 | 提高最小覆盖、调整预算或检查分层定义。 |
| `COV-002` | 告警 | 预期空层在源数据中没有可抽行。 | 核对分类字典与排除条件；这是显式提醒，不静默忽略。 |
| `COV-003` | 告警 | 最大单层占比偏差超过阈值。 | 检查分配是否被上限/容量扭曲，或放宽阈值（需审计理由）。 |
| `COV-004` | 告警 | 加权占比偏差超过阈值。 | 评估抽样代表性；考虑增大样本量。 |
| `COV-005` | 告警 | 非稀有源层没有被抽到。 | 检查层容量与最小覆盖配置。 |
| `COV-006` | 告警 | 样本出现源数据没有的层。 | 样本可能被篡改或源数据已变化；优先做重放核验。 |
| `DEV-001` | 告警 | 某层实得量超过声明上限。 | 检查执行器/样本来源；上限应视为硬边界。 |
| `DEV-002` | 告警 | 某层实得量低于声明下限。 | 检查容量、排除条款和最小覆盖策略。 |
| `DEV-003` | 告警 | 两批共有取值子集上重新归一化后的维度分布总变差距离超阈值；取值域变化另见报告 `deviance.domain_changes[]`。 | 检查上游构成变化；确认是否属于预期业务波动。 |
| `BASELINE` | 状态 | 同方案首次批次，无历史构成可比较。 | 正常；下一批新数据会自动比较。 |
| `NO_BASELINE` | 状态 | 有基线批次，但相关层与维度的共同取值子集为空，无法计算漂移距离。 | 核对两批的类别字典；确认是否只剩新增/消失取值。 |

## 台账、报告与命令行

| 代码 | 含义 | 建议处置 |
| --- | --- | --- |
| `LEDGER-001` | 无法打开或初始化台账。 | 检查目录权限、文件是否被占用。 |
| `LEDGER-002` | 台账写入失败。 | 检查磁盘空间与 SQLite 文件状态。 |
| `LEDGER-003` | 台账关闭失败。 | 检查底层文件系统；保留错误输出。 |
| `LEDGER-004` | 台账读取/查询失败，或 inspect 指定的台账不存在。 | 先运行 `samplelaw run` 生成台账，或修正 `--ledger`。 |
| `LEDGER-005` | 查询 limit 非正。 | 使用正整数。 |
| `REPORT-001` | 不支持的报告格式。 | 使用 `markdown` / `json` / `html`。 |
| `REPORT-002` | 报告写入失败。 | 检查输出目录权限与磁盘空间。 |
| `CLI-005` | 调用了 preview 但未安装 Flask。 | `pip install -e ".[preview]"`；CLI 主路径不需要 Flask。 |
| `CLI-006` | preview 的目录不存在。 | 先运行流水线或修正 `--dir`。 |

## 命令行退出码

| 退出码 | 含义 |
| --- | --- |
| `0` | 成功。`run` 总体为 `PASS` 或 `WARN` 时返回 `0`；`verify` 仅在重放 `MATCH`、覆盖 `PASS` 且总体为 `PASS` 时返回 `0`。 |
| `1` | 核验发现问题：`run` 总体为 `FAIL`；`verify` 出现重放非 `MATCH` 或覆盖/总体 `WARN`。 |
| `2` | 参数、配置、数据、台账或报告异常；`verify` 判定为 `FAIL`；`inspect` 未找到记录。 |

所有告警均写入报告的 `alerts[]` 与台账 `alerts_json`，可按批次或方案指纹复核。
