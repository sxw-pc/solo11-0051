# 使用边界与数据合规说明

samplelaw 是一个本地、离线、只读源数据的抽样核验工具。它帮助团队留下“方案如何声明、样本如何得到、结果如何核验”的证据链，但不替代数据授权、隐私评审或业务审批。

## 离线与网络

- 运行期只读取本地文件，不发起网络请求，不做 DNS 解析。
- 不包含远端采集、上传、回调、遥测、CDN 资源或自动更新逻辑。
- HTML 报告只使用内联 CSS；无脚本、无外部字体、图片或链接资源，可离线双击打开。
- 可选 Flask 预览服务仅在显式调用 `preview` 时启动，固定监听 `127.0.0.1`，只提供只读 GET 和静态文件读取；不提供上传、写入或管理接口。未安装 Flask 时 CLI 主路径和测试完整可用。
- 测试套件通过 socket 打桩验证全流程不会打开网络连接。

## 数据读取与写入

- CSV 与 SQLite 源数据按只读方式访问。SQLite 使用 `mode=ro` 只读 URI 并设置 `query_only`。
- 工具只向以下位置写入：
  - 流水线配置声明的输出目录（样本、Markdown/JSON/HTML 报告）；
  - 本地 SQLite 台账。
- 不写入远端数据库、对象存储、消息队列或任何外部系统。
- 台账包含方案、源数据、样本的 sha256 指纹和层内维度构成快照。这些内容用于审计和下一批偏离比较，应按内部数据分级妥善保存。

## 合成示例与敏感信息

- `examples/`、`fixtures/` 与 `tests/` 中的人名、组织、ID、站点和业务字段均为合成的 `demo-*` 数据。
- 示例中不包含真实密钥、令牌、账号、公司名、域名、真实邮箱、电话或可达目标地址。
- 仓库不提供外部数据下载链接，也不要求访问互联网获取 fixture。
- 重新生成示例数据的命令是 `python examples/generate_data.py`，生成结果确定性、可重复。

## 授权前提

使用本工具处理数据前，应确认：

1. 数据为本人拥有，或已获得数据所有者明确授权。
2. 抽样、保存和报告分发的范围符合组织的数据分级、隐私和保留政策。
3. 报告中的统计摘要和构成快照不超出授权范围。
4. 需要脱敏、去标识化或访问控制的场景，应由上游流程完成；samplelaw 不提供这些能力。

## 明确不实现

- 不做网络数据源连接、采集、爬虫或表单填报。
- 不做通用统计推断（置信区间、假设检验、方差分析、Bootstrap 推断）。
- 不做脱敏、数据去重或主数据合并。
- 不做数据仓库版本管理或时间旅行查询。
- 不做字段量纲契约或指标口径比对。
- 不做机器学习、建模或特征工程。
- 不做多用户、鉴权、RBAC 或在线协作。
- 不向远端系统写入；SQLite 台账是唯一落库形态。
- 不做 PDF / Excel 导出。

## 结论边界

samplelaw 给出的 `PASS` / `WARN` / `FAIL` 仅针对已声明方案下的结构、重放、覆盖和偏离指标。它不证明源数据真实、业务口径正确、抽样设计满足监管要求，也不替代统计学家或数据治理负责人的判断。任何阈值放宽、稀有层豁免和偏离接受，都应留下人工审批记录。
